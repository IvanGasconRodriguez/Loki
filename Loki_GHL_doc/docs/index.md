# Loki AI Agent

Loki es un agente de inteligencia artificial orientado a CRM que interpreta mensajes en lenguaje natural y ejecuta acciones sobre oportunidades.

## 🚀 Qué hace

- Interpreta intención del usuario usando OpenAI
- Ejecuta acciones sobre oportunidades (CRM)
- Genera resúmenes automáticos
- Prioriza leads y detecta bloqueos

## 🧠 Capacidades

- move_opportunity
- add_tag
- create_task
- resumen automático
- priorización de leads

## ⚙️ Stack

- FastAPI
- OpenAI (LLM)
- HTTPX (API externa CRM)
